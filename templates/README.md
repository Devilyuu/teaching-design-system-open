# 模板契约示例

## `课程实施大纲模板.docx`

**这是一份脱敏示例，不是任何学校的正式模板。** 它保留了代码依赖的那套结构约定，
校名、课程内容和教师信息都已抹去。换成你自己学校的模板时，照着下面的契约改就行，
具体步骤见 [`../docs/ADAPTING.md`](../docs/ADAPTING.md)。

日常使用中模板是**按课程上传**的（课程资料页 → 上传大纲模板 / 教案模板），
仓库里这一份只作契约参考和 `scripts/real_generation_check.py` 的兜底。

**深红色 `C00000` 的文字是契约**：标着「这里由 AI 生成」。黑色部分由教师自己填写，
生成过程不碰。这与教案模板用的是同一套约定，`find_unfilled_generated_cells()`
那道「导出前回头比对、漏填就中止」的闸门可以复用。

| 区块 | 谁来填 |
|---|---|
| 一、基本信息（课程编码、学分、班级、地点） | 教师 |
| （二）教师信息（含教师简介） | 教师 |
| 各级标题、表头 | 模板固定 |
| 二、课程介绍（简介 / 教学策略 / 先修要求） | AI |
| 三、预期学习成果 | AI |
| 四（一）学习内容表 | AI |
| 四（二）学习进程表 | AI（已实现） |
| 五、学习资源 | **照抄课程标准**，不经模型 |
| 六、考核方式表 | **照抄课程标准**「四、课程评价」那张表，不经模型 |
| 七、学习方法和学时建议 | AI |
| 八、学习要求和期望 | AI |

**五、学习资源和六、考核方式单独定了规矩**：教材、教辅、参考书目、平台网址都是事实，
模型编起来毫无破绽却查无此物；考核比例则是教务要对的账。这两节只允许从课程标准里
原样搬运，课程标准里没有的就写「课程标准中未提供，请教师补充」，
不许模型自己写一条出来。考核方式表**连合并一起搬**——标准里「过程考核（平时成绩）」
纵向合并了三行、末尾有一行「合计 100%」。

五（一）里「教材：」「教辅：」各自独占一行，下一行才是红字占位；生成时按条数复制占位行，
每条前加「[1] 」「[2] 」编号（课程标准自带编号的照抄，不重复编号）。

**表格只留表头 + 一行占位**。生成时按实际条数复制那一行，做法与教案模板里
`_repeat_last_block()` 复制课次区块一致。

一处可以机器验的约束，模型在这里最容易算错：
四（一）学习内容表的「参考课时」合计 = 课程总学时。
