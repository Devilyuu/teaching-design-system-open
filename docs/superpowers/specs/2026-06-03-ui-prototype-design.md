# 智能备课文档生成系统页面原型设计说明

日期：2026-06-03

## 原型目标

本原型用于验证第一版产品的信息架构、教师端核心流程和管理员端基础入口，不作为最终视觉设计稿。

原型采用本地 HTML 可点击形式，覆盖教师工作台、新建备课任务、课程实施大纲编辑、教案生成、作业试卷生成和管理员后台。

## 设计原则

- 以教师真实备课流程为主线，不做营销页。
- 界面风格采用安静、清晰、工作台式的教育 SaaS。
- 第一视觉重点放在课程实施大纲表格、教案目标校验和 Word 导出操作。
- 页面中保留生成状态、模板识别状态、能力指标校验状态。
- 复杂表格允许横向滚动，避免为了塞满页面而牺牲可读性。
- 移动端以可浏览和轻量确认优先，不承担重度表格编辑。

## 页面范围

### 教师工作台

展示备课任务、待确认事项、近期生成文档和关键状态。

### 新建备课任务

展示学期、专业、课程、班级、教师、地点、学时设置，以及课程标准、课表、课程实施大纲模板、教案模板的上传/识别状态。

### 课程实施大纲

左侧展示课程目标和能力指标代码，中间展示课程实施大纲中的授课计划部分，右侧展示校验结果。

表格支持 `contenteditable`，用于表达后续网页内编辑能力。

### 教案生成

左侧展示 8 次课列表，中间展示单次课教案结构，右侧展示 `K -> M -> 能力指标代码` 校验。

### 作业试卷

支持按课次选择作业/试卷，展示任务说明、提交要求、评分标准和生成依据。

### 管理员后台

展示人才培养方案库、课程标准库、模板库、AI 与校历配置四类基础入口。

## 验证记录

已用 Microsoft Edge + Playwright 做本地检查：

- 桌面端页面可打开。
- 移动端页面可打开。
- 主导航可切换。
- 课程实施大纲表格可编辑。
- 浏览器控制台无错误。

## 2026-06-04 优化记录

根据可理解性走查，已完成一轮简化：

- 教师工作台改为“上传资料和模板、点击生成初稿、确认或简单修改、导出 Word 文档”的四步主流程。
- 明确提示导出的 Word 可继续在 WPS/Office 中修改。
- 顶部操作按钮改为随页面变化，不再所有页面都显示同一个“导出 Word”。
- 课程实施大纲表格减少首屏列数，只保留课次、日期、周次、节次、教学内容和学习任务。
- 课程思政、教学方法、能力指标等信息移到右侧详情和自动检查区域。
- 左侧导航将管理员入口弱化为“标准库与模板库”，减少普通教师的干扰。

## 2026-06-04 视觉风格调整记录

根据参考的钉钉管理后台风格，原型已调整为蓝色顶栏、白色侧栏、浅蓝工作区和白色卡片的后台管理台视觉。此次调整不改变产品流程，仍然围绕“上传资料与模板、生成初稿、网页确认或修改、导出 Word 文档”展开。

为保证教师端可用性，课程实施大纲和教案生成页面在常见笔记本宽度下改为两列优先布局：左侧保留资料/课次导航，中间保留主要表格或教案预览，右侧校验与详情信息自动下移，避免表格编辑区和教案预览区被挤压或裁切。

## 2026-06-04 第二版视觉尝试记录

根据“永电云”类业务工作台参考图，原型进一步调整为白色顶栏、白色侧栏、浅灰工作区、青蓝主色和细线卡片风格。相比上一版蓝色外框后台，本版更轻、更接近教师日常工具，不强调企业管理后台的厚重感。

页面结构保持不变：教师仍从工作台进入上传、课程实施大纲确认、教案生成和作业试卷生成流程。视觉上重点降低大面积蓝色占比，用青蓝色承担当前导航、主按钮、提示条和校验状态，增强清爽感和长时间使用的舒适度。

## 2026-06-05 第三版视觉尝试记录

根据 SHS 酒店 SaaS 后台参考图，原型调整为浅蓝灰画布、居中系统框、白色顶栏、窄白侧栏、深蓝主色和橙色强调色。视觉关键词是“轻后台、卡片分区、深蓝操作、橙色提醒、细线边框、柔和投影”。

本版保留教师备课业务结构不变，只迁移视觉语言：当前导航使用左侧深蓝竖条和浅蓝底，主按钮使用深蓝，提醒/处理类状态使用橙色，页面主体采用浅蓝灰背景与白色卡片，桌面端呈现参考图中的居中后台界面效果，移动端恢复满宽浏览。

## 2026-06-06 减法审查与空间优化记录

根据全面审查结果，原型删减和压缩了装饰性强、操作价值弱的模块：教师工作台移除“近期文档”首屏卡片，四步流程卡改为更紧凑的操作提示，减少展示型留白。

页面布局从居中小画布调整为接近全浏览器宽度的工作台。课程实施大纲和教案生成页面把需要手动编辑的表格、目标和教案正文作为主区域，生成依据、当前课次详情、指标校验等辅助信息下移或缩窄，不再挤占主编辑区。移动端保持满宽浏览，不承担重度表格编辑。
