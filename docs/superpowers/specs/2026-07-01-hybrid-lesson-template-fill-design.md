# 混合式教案模板填充设计

## 目标

确保整门课教案导出真正填入教师上传的 Word 模板，而不是在模板末尾追加普通文本。系统优先使用显式占位符；模板没有占位符时，识别学校教案中的重复课次区块并原位填充。

## 模式顺序

1. **占位符模式**：存在 `{{教案正文}}` 时按现有方式替换，兼容会自行制作模板的教师。
2. **结构识别模式**：不存在占位符时，识别由“本次课标题”“授课学时”“授课班级”“上课时间”“上课地点”“本次课教学目标”“课程教学目标”“能力指标代码”等字段组成的课次信息表，以及紧随其后的“教学环节（时长）/教学内容/教师活动/学生活动/对应教学目标”过程表。
3. **拒绝模式**：既无占位符，也无法可靠识别课次区块时停止导出并返回明确错误，不追加纯文本。

## 结构识别规则

- 课次信息表必须同时包含“本次课标题”“授课学时”“本次课教学目标”“能力指标代码”。
- 教学过程表必须同时包含“教学环节”“教学内容”“教师活动”“学生活动”“对应教学目标”。
- 每个信息表与其后最近的过程表组成一个课次区块。
- 模板区块数必须不少于待导出教案数；第一版不复制复杂课次区块，避免破坏分页、合并单元格和页眉页脚。
- 单元格写入只替换文本内容，保留表格、行列、合并关系、宽度、边框、底纹和段落格式。

## 字段映射

课次信息表：

- 课程名称、任课教师、授课班级、上课地点来自学期课程。
- 本次课标题来自 `LessonPlan.title`。
- 授课学时来自 `duration_minutes / 40`。
- 上课时间来自对应实施大纲行的周次、星期和节次。
- 本次课教学目标来自 `teaching_goals`。
- 课程教学目标来自 `course_goal_codes`。
- 能力指标代码来自 `ability_codes`。

教学过程表：

- 第一版将现有 `teaching_process` 按“课前、导入、讲授、实训、总结、课后”标签拆分。
- 能识别的过程行按标签填入“教学内容”。
- 无法拆分的文本整体写入第一条课中行，不编造教师活动和学生活动。
- `homework` 写入课后行。

## 错误处理

- 模板没有可识别课次区块：返回“教案模板未识别，请添加占位符或使用学校标准模板”。
- 模板课次区块少于教案数量：返回实际区块数和所需数量，不生成残缺文件。
- 单个课次缺少实施大纲关联信息：保留模板中的时间字段，不伪造日期。
- 导出失败不修改数据库中的教案内容和模板文件。

## 验收标准

1. 真实完整教案模板识别出 8 个课次区块。
2. 8 份教案分别写入 8 个原有区块。
3. 导出后表格数量、合并关系、节属性、页眉页脚和图片数量保持不变。
4. 不含占位符且无法识别的模板明确拒绝。
5. 占位符模板继续兼容。
6. 真实模板导出后完成逐页渲染检查，无新增空白尾页、错位表格或正文追加区。
